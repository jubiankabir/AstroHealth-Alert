# AstroHealth-Alert

AstroHealth Alert utilizes real-time health data gathered from pre-existing devices and tracks it as a graph on its website. Unfortuantely, we couldn't find any public databases to access real astronauts health data so we instead used simulated data from MATLAB to showcase the idea. AstroHealth Alert would use the collected data and interpret whether or not the astronaut's health is at risk. If the astronaut's health is in critical danger, AstroHealth Alert would prompt immediate action and to take preventative care such as seeking nearest shelter to avoid further radiation exposure. AstroHealth Alert would signicantly reduce health risks on space missions and help astronaut stay safe while in space. We used MATLAB, with the help of Copilot (how did we use copilot btw), to simulate data that would reflect the real-time data from astronauts. We then developed the website using HTML and CSS on Visual Studio Code. Our project's creativeness lies in the graphic design of the website and how we built on pre-existing devices, such as health monitoring devices, to further help astronauts. Factors our team considered are how there are already devices such as Garmin and Biomonitor that exists on the market. However, AstroHealth Alert takes those data and interprets it to communicate the danger level to the astronaut in real time.
